:::caution[No knowledge skill at this commit]
The repo at `d1860fe` ships no knowledge skill for coding agents. This page stays in place and will be written from it when one exists.
:::

What exists today: each component has a `<Name>.intent.json` beside it in `src/components/`, transposed from its Figma documentation page, its code and its stories. It holds when to use the component, when not to, best practice, what each variant is for, the tokens it needs and its accessibility facts with source lines. The Usage tab of every component page is rendered from it. The intent files live in the repo; the npm package ships only `dist/`.
