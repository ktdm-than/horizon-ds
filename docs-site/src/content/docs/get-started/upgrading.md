description: Moving from one published version to the next.
---

:::note[Nothing to upgrade from yet]
`0.1.0` is the first published version (tag `v0.1.0`), so there is no earlier version to upgrade from. This page gets a section for each later release that changes something a consumer imports, taken from the changelog's Changed and Removed headings, as [Versioning](/get-started/versioning/) requires.
:::

While the package is `0.x`, a minor bump may break things. Each breaking change is listed under Changed or Removed in the [changelog](/get-started/changelog/), with what to change in your code.
